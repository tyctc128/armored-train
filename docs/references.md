# 視覺重繪：參考資料與判斷

重繪目標是「像上了色的老照片」。這份文件記錄每個部分依據什麼資料、我據此做了什麼判斷。
參考照片多半有版權，不放進 repo，只列出處。標「待核對」的項目是依一般軍事史知識先做的，還沒逐一對照照片。

## 時期與場景

- 時期：昭和九年（1934）十二月，九四式裝甲列車試驗運行。出處：影片《昭和九年十二月 九四式裝甲列車 試驗実况》（NFAJ「フィルムは記録する」），已列於 `docs/GDD.md`。
- 場景：滿洲平原初冬。判斷：枯草、落葉後的楊樹與柳樹、遠處山頭積雪、平地零星殘雪、薄霧。

## 列車

- 外觀與內裝：依《世界裝甲列車圖解百科》的照片重建（各車廂腳本開頭的說明記有照片內容）。
- 塗裝：1934 年試驗運行時的迷彩——深橄欖底、低對比褐色斑、細的黃赭色彎曲條紋（見 `tools/blender/common.py` 的 `camo_texture`）。
- 做舊程度：試驗時是新造車，所以只做輕到中度的使用痕跡——下緣揚塵、車頂煤煙、雨水流痕、零星掉漆；鏽只出現在底架、輪對、連結器。
- 車內：偏暗，電燈泡暖光；牆面下半有踢痕與積塵。

## 人物

- 人體：MPFB（MakeHuman）產生，亞洲男性、青年、中等體格，身高 1.66 m。
- 我軍軍服（待核對）：昭五式軍衣（立領、領章、五顆鈕扣、胸前口袋）、短袴、綁腿、編上靴。
- 我軍帽子（待核對）：步兵戴九〇式鉄帽；車組員與軍官戴軍帽（紅色帽圈、星章）。先前的模型用的是 1938 年才制定的略帽樣式，這次改掉。
- 冬季防寒外套與防寒帽：尚未製作（背囊上只有捲起的外套）。
- 敵軍：架空設定不變，灰綠軍服、平頂軍帽、藍領章。
